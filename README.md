# Playstead by ChunkArc

Official release files and bug reports for Playstead, a Windows app for running Minecraft and Terraria servers on your own PC.

Technical prereleases are available for in-app update trials. General public-beta readiness checks are still in progress. This repository does not contain the app's source code or signing credentials. Playstead is proprietary software; bundled third-party components keep their own licenses.

## Downloads

The [Releases page](https://github.com/Foremast691/local-studio-releases/releases) contains the installer, update manifest and limitations for the current trial. The installer is not Authenticode-signed; Windows may show unknown-publisher or SmartScreen warnings. The installed app verifies a separate update signature and the installer hash. Never disable Windows security protections to run an installer. Read the prerelease notes and keep a separate backup before testing.

Servers run on your computer, not on ChunkArc hosting. Your PC and the app must stay on while friends are playing. Internet sharing uses your own Playit account and is subject to that service's availability and plan. Terraria/tModLoader features are experimental; do not assume Minecraft's sharing support applies to them.

## Report a bug

Use the **Bug report** form in [Issues](https://github.com/Foremast691/local-studio-releases/issues/new/choose). Include the app version, Windows version, game and steps needed to reproduce the problem.

New beta candidates have **Settings → Support and diagnostics → Prepare report**. Review the preview before sharing it. This report contains version/system information and world counts, not chat, player names, paths, addresses or credentials. Nothing is submitted automatically. Older installers may not have this feature.

Do not attach entire worlds, private configuration files, passwords, tokens, pairing links, IP addresses or original console logs without reviewing them. Original console log exports are not anonymized. Never post sensitive security details in a public issue.

Always keep a separate backup of worlds and mods before trying beta software. Test candidates and QA fixtures are not stable releases.
